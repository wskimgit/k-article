## 필수 실행 순서
`원자료·권리 검증 → 핵심 메시지 하나 확정·자료 연결성 확인 → 기사·이미지 제작 → 사실·메시지·지재권 최종 검증 → 저장·확인 → 종료`

1. 실제 사용할 자료의 사실과 이용 권한을 각각 확인한다. 정당한 배포처·사용 요소·사용 방식·재사용 근거·조건 이행을 기록한다. 공식자료·무료 열람·출처 링크·AI 재서술만으로 PASS하지 않는다. 최소 사실도 별도 허락 불필요 근거와 약관·데이터베이스 제한을 확인하며, 확인 없이 예외를 추정하지 않는다.
2. 자료별 PASS/EXCLUDE/UNCLEAR를 사용한다. PASS만 채택하고 나머지 내용·계산·해석·이미지 입력을 제외한다. 같은 사실은 허용된 독립 원자료에서 새로 확인한다. 작업 전체 보류는 HOLD다.
3. '누가 FAB의 무엇을 어떻게 바꾸어 어떤 운영·사업 변화가 생기는가'에 한 문장으로 답하고 메시지를 먼저 확정한다. 각 자료가 어느 주장을 뒷받침하는지 기록한다. 키워드·업종·시점만 같은 무관한 자료와 의존 내용을 기사·이미지·출처에서 함께 제거한다.
4. 계획·시연·시제품·고객 평가·양산 도입, 발표일·사건일·관측 기간과 측정조건을 구분한다. 여러 국가·기업을 억지로 섞지 않고 한 사건의 허용 원자료만으로 충분하면 그 범위에 집중한다.
5. 문장·구성·계산·사업 및 투자 해석을 직접 만들고, 제목·리드에서 마지막 문단까지 한 메시지를 잇는 일반 기술기사로 완성한다. 끝 문단은 사실을 종합한 하나의 의미로 맺고 후속 일정은 메시지를 바꿀 조건일 때만 넣는다.
6. 자료 기준 KST 시각과 AI 고지를 표시하고 기사 맨 아래에 **참고자료 → 지재권 확인**을 순서대로 넣는다. 실제 사용한 연결성 검증 PASS 출처와 이번 이용 근거·범위·조건 이행·이미지 자체 제작 여부를 표시한다. 법적 무침해를 보증하지 않는다.
7. 사용 전 권리 불명확 후보는 제외한다. 제작 중인 기사나 이미지에서 침해 요소가 확인되면 **두 초안을 모두 폐기하고 원자료부터 다시 검증해 기사와 이미지를 함께 새로 작성**한다. 부분 삭제·이미지 단독 교체·기사만 게시로 우회하지 않는다.
8. 전면 재작성은 1회이며 기존 조사 보완·확장 합계 1회·이미지 생성 총 2회·일반 편집 수정/재검증 1회 한도를 초기화하지 않는다. 잔여 한도가 없거나 재작성본도 침해 요소·핵심 근거 부족·사실 모순이 남으면 폐기본을 제외하고 HOLD한다. 일반 비침해 이미지·저장·연동 실패의 PARTIAL과 구분한다.
9. 기존 `chatgpt/copyright-checks/YYMMDD.<식별자>.json`에 사실·권리 근거·메시지 연결·독자 작성·최종 검토·제외 및 재작성 횟수를 기사 stem과 연결해 기록한다. 실제 저장과 NAS 공개 확인은 구분하여 확인한 단계만 완료라고 보고한다.
10. 기존 이미지 동일 SHA도 최종 검증을 면제하지 않는다. 전면 재작성에서 폐기한 이미지와 기사 내용은 재사용하지 않는다. 저장 오류는 적합한 기존 바이너리로 한정 재시도한다.

## 유지되는 이미지 전송 규칙 — GITHUB-SAFE IMAGE PROFILE
1. GitHub 게시용 이미지는 고품질 원본과 분리된 경량 JPEG로 저장
2. 기본 1200×675 / RGB / 메타데이터 제거 / 4:2:0
3. JPEG Quality 약 35~40, 목표 파일 크기 **12 KB 이하**
4. 12 KB 초과 시 같은 이미지에 대해 압축 조정은 1회만 허용
5. 그래도 초과하면 960×540 fallback 1회
6. 품질값 반복 탐색 및 다중 `q*.jpg` 시험파일 생성 금지
7. GitHub 저장 전 SOI `FF D8` + EOI `FF D9` + 실제 decode + 해상도 확인
8. GitHub 저장 후 원격 바이트 길이 = 로컬 바이트 길이 확인
9. 원격에서도 SOI + EOI + 해상도를 확인해야 COMPLETE
10. SOI만 맞는 잘린 JPEG는 PASS 금지
11. 저장 실패를 이유로 이미지 재생성 금지
12. 성공 후 원격 확인 1회만 수행하고 즉시 종료

## HARD STOP
- 조사 보완·확장 합계 1회 후에도 핵심 근거·권리 근거 부족
- 이미지 생성 총 2회 후에도 적합 이미지가 없거나 전면 재작성용 새 이미지 제작 불가
- 전면 재작성 1회 후에도 침해 요소·사실 모순·핵심 근거 부족
- 일반 편집 수정·재검증 1회 후에도 오류가 남음
- 안전 JPEG 변환 기본 1회 + 압축 조정 1회 + 해상도 fallback 1회 후에도 바이너리 요건 미충족
- GitHub 저장 충돌 재시도 최대 1회
- 동일 SHA의 정상 재사용 확인 또는 원격 완전성 검증 성공 즉시 종료
- 우회 저장 경로 탐색 금지
