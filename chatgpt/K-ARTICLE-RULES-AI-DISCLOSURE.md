# K-ARTICLE 생성형 AI 작성·제작 고지 v1.2 — FROZEN

기준일: 2026-11-25
상태: FROZEN / 기사 규칙 v2.7·이미지 규칙 v2.9에 대한 필수 고지

## 0. 적용 원칙
KNEWS v2.7의 말미 표기와 확인 범위 공개 방식을 EGTECH에 맞춰 적용한다. 기사 규칙 `chatgpt/K-ARTICLE-RULES.md` v2.7 §5.1·§6.1·§6.2·§8~§9와 이미지 규칙 v2.9를 함께 따른다.

고지나 출처 링크는 재사용 허락·실제 권리 검증을 대신하지 않는다. 정당한 원자료의 사실과 이용 근거를 확인한 PASS 자료만 사용한다. EXCLUDE/UNCLEAR 자료와 그에 의존한 내용·계산·해석·이미지 입력은 제외한다. 제작 중 침해 요소가 확인되면 기사·이미지를 함께 새로 만들고, 기존 전체 한도를 넘거나 재작성본도 실패하면 HOLD로 종료한다.

## 1. 기사 고지와 말미 순서
마지막 본문 문단 뒤에 다음 고지를 표시한다.

`※ 본 기사는 재사용 근거가 확인된 공개자료의 사실을 바탕으로 생성형 AI가 작성·편집했습니다.`

검증을 실제 완료한 결과에만 이 문구를 적용한다. 검증 전 고지만 붙여 채팅으로 출력하거나 저장·게시하지 않는다. 정정·교체 기사에는 수정 시각·변경 요지를 표시한다.

채팅용과 저장·게시용 모두 기사 맨 아래에 다음 두 항목을 순서대로 넣는다.

**참고자료 —** 최종 기사 또는 이미지에 실제 사용했고 핵심 메시지에 연결되는 PASS 원자료만 기관명·자료명·발표일/기준일·열리는 원문 URL과 함께 적는다. 자료가 요구하는 저작자·라이선스/조건 링크·가공 사실도 표시한다. 빠진 자료를 참고자료에 남기거나 확인하지 않은 허락을 만들어 쓰지 않는다. 게시용 본문에 채팅 전용 인용 ID를 넣지 않는다.

**지재권 확인 —** 실제 사용한 자료의 이용 근거·범위·조건 이행·최종 검토 결과를 짧게 적는다. 자체 생성 대표이미지이면 자체 제작한 산업현장 예시 이미지임을 밝힌다. 확인 범위에서 침해 요소가 발견되지 않았으면 그 범위를 밝혀 적고, 법적 무침해 보증으로 표현하지 않는다. 확인하지 않은 '문제없음' 문구나 다른 기사의 확인 문구를 복사하지 않는다.

위 말미 표기는 독자용 요약이며 기존 내부 검증표 `chatgpt/copyright-checks/YYMMDD.<식별자>.json`의 저장을 대신하지 않는다.

## 2. 대표이미지 고지
기존 EGTECH의 산업현장 사진형·16:9·JPEG 규격을 유지한다. 대표이미지 우측 하단에 다음 문구를 식별 가능하게 표시한다.

`생성형 AI 제작 이미지`

기사 내용을 가리지 않는 작은 글자와 배경 대비를 확보한다. TXT와 JPG의 stem·버전·바이너리 검증 규칙은 유지한다. KNEWS의 기자명·비실사 삽화 고지로 자동 전환하지 않는다. AI 고지를 실제 현장 촬영·실제 고객 도입의 증거로 사용하지 않는다.

## 3. ERRC 추가 검증
다음을 내부 기록과 최종 결과에서 함께 확인한다.
- 자료별 사용 범위의 근거·조건 이행과 사실 검증이 갖춰졌는가
- 제목·리드·본문·마지막 문단·이미지와 실제 출처가 하나의 메시지로 연결되는가
- EXCLUDE/UNCLEAR 자료와 의존 내용이 제거되고 문장·구성·계산·사업 및 투자 해석을 독자적으로 작성했는가
- 일반 기사체·자료 기준 시각·기사/이미지 AI 고지·말미 참고자료와 지재권 확인이 있는가
- 침해 요소 발견 시 두 초안을 폐기하고 한도 안에서 전면 재작성했는가
- 실제 수행한 저장·공개 확인 단계만 완료라고 보고하는가

일반 편집 수정 1회·재검증 1회, 전면 재작성 1회와 전체 이미지 생성 최대 2회의 한도를 초기화하지 않는다. 미충족 결과를 ERRC PASS 또는 COMPLETE로 보고하지 않는다.
